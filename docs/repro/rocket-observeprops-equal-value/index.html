observeProps ignores an attribute write whose decoded value is unchanged

Datastar v1.0.4 + Rocket. A component that lets the server own a boolean (or clear a string) cannot tell when the server writes the attribute, if the decoded value happens to equal the prop's current value — even though the component's local state has moved on since.

The consequence

  1. Click A's button to switch it ON (local state, the user's doing). A has no open attribute.
  2. Click server: A open="false". The attribute is written, but observeProps never runs, so A stays ON.
  3. Now click server: B open="false". B started with open="true", so the decoded value changes, observeProps runs, and B turns off.
